Package grails.plugins.passwordless

  • Interface Summary 
    Interface Description
    LoginAccountLookup How the plugin finds a user.
    LoginLinkSender Delivers a login link: by mail, SMS or whatever the application uses.
    LoginPrincipal What the session holds after sign-in.
    LoginPrincipalFactory Builds the session principal for an account that has just proved who they are.
    LoginSuccessRedirect Where a user goes after signing in by magic link.
    SessionPolicy How long a session may sit idle.

    PasswordlessUrlMappings The plugin's URLs.

Package grails.plugins.passwordless.passkey

  • Class Summary 
    Class Description
    NotifyingUserCredentialRepository Spring Security's credential store, announcing every passkey it stores for the first time.
    PasskeyRegisteredEvent A passkey was added to a user's account.
    PasskeyRegistrationAuthorization Who may add or remove a passkey: a signed-in person whose session has confirmed a passkey, or anyone adding their first.
    PasskeyRegistrationGuard Applies PasskeyRegistrationAuthorization in front of Spring Security's registration filters.
    PasskeySettings The WebAuthn relying party: by default the host and origin of grails.serverURL, the address users reach the application at. passwordless.passkeys.rp-id and passwordless.passkeys.allowed-origins override it, which only a test with a browser in a container needs.
    PasskeySignInHandler Ends a passkey sign-in exactly as a magic link ends: the session gets the application's principal, a new id, a fresh CSRF token and the same idle timeout.

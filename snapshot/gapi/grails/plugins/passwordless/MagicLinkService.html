[Groovy] Class MagicLinkService

    • grails.plugins.passwordless.MagicLinkService
    • All Implemented Interfaces and Traits:
      GrailsConfigurationAware
      @groovy.util.logging.Slf4j
class MagicLinkService
extends java.lang.Object
implements GrailsConfigurationAware

      Issues and redeems magic links. This is session recovery, not signup: it never creates an account, and answers identically whether or not the address is known.
